# Live Typewriter Screen Pro

Минималистичный генератор экрана с эффектом живого набора текста (Typewriter), оптимизированный для создания контента в TikTok, Reels, Shorts и YouTube. Приложение работает автономно (один HTML-файл) и исполняется прямо в браузере без серверов.

## 🚀 Возможности (Features)

- **Мгновенный отклик (Live Typing):** Текст транслируется в центр экрана по мере его набора.
- **Синтезатор звука клавиатуры (Web Audio API):** Имитация звука механической клавиатуры при каждом нажатии клавиши. Не требует загрузки внешних аудиофайлов. Включается в настройках, громкость регулируется.
- **Форматы холста (Aspect Ratios):**
  - `Free / Fullscreen` — на весь экран (отличный выбор для Mac/Windows записи экрана).
  - `9:16` — Вертикальный формат (TikTok, Instagram Reels, YouTube Shorts).
  - `1:1` — Квадрат (Instagram Post).
  - `16:9` — Горизонтальный формат (YouTube, Presentation).
- **Экспорт PNG в высоком разрешении:** Встроенная интеграция `html2canvas` позволяет одним кликом сохранить чистый холст (без элементов интерфейса) в PNG формате.
- **"Clean Mode" (Скрытие интерфейса):** Скрывает курсор мыши, кнопки, панель ввода и настройки. Идеально для чистой записи экрана.
- **Глубокая кастомизация (Сохраняется в localStorage):**
  - Подбор цвета фона и шрифта (как пресеты, так и Custom Color Picker).
  - Выбор эстетичных шрифтов (Inter, Montserrat, Bebas Neue, Playfair, JetBrains Mono, Courier Prime).
  - Точная настройка типографики (размер, жирность, межстрочный и межбуквенный интервалы).
- **Горячие клавиши (Hotkeys):**
  - `Enter` — мгновенно очищает экран и инпут для ввода новой мысли/строки.
  - `H` (или `Р` в рус. раскладке) — включить/выключить Clean Mode (скрыть интерфейс).
  - `F` (или `А` в рус. раскладке) — переключить полноэкранный режим браузера.
  - `Esc` — закрыть настройки или выйти из Clean Mode.

## 🛠 Технологии

- **Vanilla JavaScript** (чистый JS без фреймворков, логика в одном файле)
- **Tailwind CSS** (через CDN для мгновенной стилизации)
- **Web Audio API** (встроенный браузерный аудио-движок для синтеза кликов)
- **HTML2Canvas** (через CDN для сохранения PNG скринов)
- **Lucide Icons** (через CDN для минималистичных иконок)
- **Google Fonts**

## 💻 Установка и Запуск

Приложение состоит всего из одного файла `index.html`. 

1. **Локальный запуск:**
   Просто откройте файл `index.html` двойным кликом (он откроется в вашем браузере по умолчанию — Chrome, Safari, Edge, Firefox).
2. **Деплой:**
   Файл можно загрузить на любой статический хостинг. Отлично подойдут GitHub Pages, Vercel, Netlify или Cloudflare Pages. Просто перетащите папку с файлом в панель Vercel/Netlify Drop.

## 📱 Инструкция для контент-мейкеров

1. Откройте `index.html` в браузере.
2. В правом верхнем углу нажмите иконку шестеренки, чтобы открыть настройки.
3. Выберите нужный **Формат холста** (например, 9:16 для TikTok). Холст автоматически отцентрируется.
4. Выберите шрифт, цвета и настройте **Звук клавиатуры**.
5. Запустите программу записи экрана (например, OBS, QuickTime, или Win+Alt+R).
6. Нажмите горячую клавишу `H`. Весь лишний интерфейс (кроме самого текста) исчезнет, курсор мыши спрячется.
7. Печатайте ваш текст "вслепую". Звук кликов будет записываться в видео, а текст появляться на экране. Нажимайте `Enter` для очистки строки и перехода к следующей мысли.
8. Остановите запись экрана. Ваш эстетичный видеоряд готов!
